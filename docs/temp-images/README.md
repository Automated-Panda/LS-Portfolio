# 📸 Marketing screenshot drop folder

Drop your 4 app screenshots here (any common format — PNG/JPG/WebP). Claude will
crop/normalize them to the right WebP dimensions and place them in public/marketing/.

Capture from http://localhost:3000 while logged in, browser window wide (≈1440px+),
in dark mode. Name them so it's obvious which is which (or just tell Claude):

- `dashboard.*`  → the /dashboard view (hero shot — make it look loaded)
- `vehicles.*`   → the /vehicles browser
- `property.*`   → a property detail (open a loaded property with cars in it)
- `organizer.*`  → /organize (ideally showing a plan, for the "Pro" teaser)

Tip: a clean full-window capture beats a tiny region — Claude resizes down, not up.
The OG share image gets generated separately from the logo (no screenshot needed).
